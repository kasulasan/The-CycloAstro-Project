# The CycloAstro Project — Scope and Deliverables

## Overview
The CycloAstro Project is a hybrid Python and C framework for simulating and analyzing celestial dynamics.  
It combines C-based performance with Python-based modeling and visualization to study gravitational systems.

---

## Objectives
1. Develop a modular C simulation engine for multi-body dynamics.
2. Integrate C and Python for analysis and visualization.
3. Use Rebound and Astropy for accurate orbital modeling.
4. Build clear, reproducible tools for research and teaching.

---

## Scope
**Included**
- Core C simulation engine
- Python analysis layer
- Visualization tools using Matplotlib
- Reproducible environment (Make + Conda)

**Excluded (Future Work)**
- GPU acceleration
- Large-scale parallel computation
- Integration with real-time astronomical data

| Phase | Deliverable | Description |
